Apa Itu JavaScript?

JavaScript (JS) adalah bahasa pemrograman tingkat tinggi, dinamis, dan terinterpretasi yang dirancang untuk membuat halaman web menjadi interaktif dan dinamis. Bersama dengan HTML (struktur) dan CSS (tampilan), JavaScript merupakan salah satu dari tiga teknologi inti pembuatan World Wide Web.

Tanpa JavaScript, sebuah website hanya seperti brosur cetak statis. Dengan JavaScript, website dapat merespons aksi pengguna seperti klik tombol, menampilkan galeri gambar interaktif, memuat data tanpa *reload* halaman (AJAX/Fetch), hingga mengoperasikan game di browser.

Sejarah Singkat JavaScript

  • 1995 Brendan Eich merancang JavaScript hanya dalam kurun waktu 10 hari saat bekerja di Netscape Communications. NAMA awalnya adalah Mocha, lalu diubah menjadi LiveScript, dan akhirnya JavaScript.
  • 1997 JavaScript disahkan di bawah standar internasional bernama ECMAScript (ECMA-262) untuk menjaga konsistensi antar browser.
  • 2009 Peluncuran Node.js memungkinkan JavaScript dijalankan di luar browser (Server-side), merevolusi dunia backend development.

Fitur & Karakteristik Utama

Client-Side & Server-Side

Dapat dieksekusi langsung di browser pengguna (Client) maupun di peladen (Server via Node.js).

Asynchronous Programming

Mendukung Promises & async/await untuk menangani proses berat tanpa membuat browser membeku.

Dynamic Typing

Tipe data variabel ditentukan secara otomatis saat *runtime*, memudahkan penulisan kode awal dengan cepat.

Event-Driven Architecture

Merespons tindakan nyata pengguna secara *real-time* seperti klik, scroll, ketikan keyboard, dan drag-and-drop.

Pertanyaan Sering Diajukan (FAQ)

Tidak! Meskipun memiliki nama yang mirip, Java dan JavaScript adalah dua bahasa pemrograman yang sama sekali berbeda dalam hal desain, tujuan, dan sintaksis. Kata "Java" dimasukkan saat pemasaran pada tahun 1995 karena Java sedang sangat populer saat itu.
JavaScript dianggap sebagai salah satu bahasa paling ramah pemula (*beginner-friendly*). Anda tidak memerlukan setup perangkat lunak yang rumit—cukup buka browser di PC/Laptop/Tablet Anda dan Anda bisa langsung menulis kode JavaScript!
DOM adalah representasi struktur standar dari halaman HTML yang dibuat oleh browser. JavaScript menggunakan DOM untuk merubah, menambah, memodifikasi, atau menghapus elemen dan gaya CSS secara dinamis saat web berjalan.
